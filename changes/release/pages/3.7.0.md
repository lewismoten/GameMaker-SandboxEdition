# Site 3.7.0 - 2026-11-15

Every change in this version (tag `pages-v3.7.0`). The [changelog](../../../CHANGELOG.md) has the summary and the most important changes.

Stick Man Stars moves onto paper, Lucky Cat 4.0 plays harder, First Steps gets a jump you can steer, the Starters' signs are centered and easier to read, the editor fits phones better, and the big offline download is paused while it is rebuilt.

### Added

- The Level check lets you type a short reason when you mark a finding as checked or on purpose, and shows it with the accepted finding.
- The character editor can show the hero in front of a light grid as well as the dark one.
- FLAGS.EXE on the desk's PC can now list, set, clear and reset Starter course grades (so graduations can be tried at 3 of 8), Scoot's mail, the desk buddy, the rubber chicken and the last "What's new" visit, and FLAGS.BAK keeps them too.
- Stick Man Stars: forks on Repo Row, smaller copies of their houses with a fork for a weathervane, and the Big Repo now stands as a fork of a weathered old original.
- Stick Man Stars, a short Special: a stick figure picks stars out of the night sky on a hill, then tosses them at little made-up repo houses (shy ones that wander, a shed that blocks a tunnel, spam bots with fading fake stars and a Big Repo with three lanterns to light), in four levels from night to dusk.

### Changed

- The Cast page folds each regular's game pictures and roles into one "Seen in" list that opens on a tap, so the page is much shorter, and the small follow-along stage now docks at the bottom left with the name readable and room left at the page end.
- On a phone the editor header is compact: the file name rides in the breadcrumb, Assets, find, shortcuts and the Assistant move into the ⋯ menu, Used by and Uses fold into one button, and the working area starts on the first screen.
- Editors on short windows give the work area more room: Used by and Uses share a row, the block set limit note folds into the tip, and the slide show preview shrinks.
- The Level check no longer offers "Mark as checked" on a problem that will fail for players (a missing file, a link that can never fire, a number past what DOS keeps): it shows "Go to it" instead, and an older game that had set one aside shows it again.

- The home page's collection tabs now wrap to two rows on a mid-width window (they were three) and to three rows on a phone (they were four), so more games show on the first screen.

### Security

- Importing a saves zip with a folder named like a built-in object (such as `__proto__`) no longer alters the page.
- An exported game page links the About website only when it is an http or https address; any other kind of address shows as plain text.
