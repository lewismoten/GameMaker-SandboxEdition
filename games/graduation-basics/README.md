# Graduation: First Steps

The shared graduation kit builds this game’s campus arrival and ceremony hall.
`src/levels.ts` applies `src/microSigns.ts` after the themed layout is complete.
The other six graduations opt into the same plaque plan through their own
`src/levels.ts`. It uses the kit’s shared palette and micro-plaque builder,
retains the gameplay blocks and finished map boundaries, and replaces the old
sign inventory with only the plaques each level uses.

The course labels precede their demonstrations. Hall plaques stand on at most
one block of post, and the two Doc Leo/scroll boards share their lower board’s
post. Hanging banners and course labels float. The first arrival’s welcome reads
WELCOME / GRADS to fit the micro font’s eight-character line limit.
