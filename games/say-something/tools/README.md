# Say Something: tools

- `check.ts`: the bot plays both levels and must win without losing a life. `route.ts` asserts that walking into Pip, Moss and Dot each opens that friend's own talk scene (scenes 4, 5 and 6) and brings Kit back to the room three blocks past the friend, then counts all eighteen coins.
- `walkthrough.ts`, `gendemo.ts`: re-record the walkthrough and the title demo (level 1 up to the walk into Pip).
- `demoCheck.ts`: plays the built `demo.rec` headless and checks it walks into Pip.
- `preview.ts`: PNGs of the blocks, the hero, each level and every picture.

A talk has no mistake to show: nothing here hurts, and a friend always talks when touched, so the demo and walkthrough act out each lesson once (reading the boards, talking, a two-page talk).
