MAXIMUS: THE HUNDRED WORLDS
HOW FAR GAME-MAKER GOES
==============================

Maximus was built to find the
edges of Game-Maker 3.0 and to
stand on them. These are the
limits we found in its file
formats and in PLAYGAME, and
how close this game comes.

SCENES IN A .GAM
  Limit: 231 (PLAYGAME
         allocates all scenes
         in one 64K block of
         283-byte records)
  Used:  100: title, ending,
         training deck,
         galaxy, 5 sectors, 88
         worlds, Maelstrom,
         Citadel, Heart. We
         stopped at 100: 28300
         bytes of scene
         records sit easily in
         DOS memory, every
         scene still loads in
         a moment, and the
         integrator's 310x165
         world view still
         shows each scene box
         and link
  Where: MAXIMUS.GAM

SCENE FILE-NAME POOL
  Limit: 65,520 bytes
         (PLAYGAME clamps it
         at 0xFFF0)
  Used:  2952 bytes
  Where: MAXIMUS.GAM

LINKS PER SCENE
  Limit: 20
  Used:  20 (a sector chart:
         the warp home, 18
         planets and the jump
         ring onward)
  Where: SECTOR1..5

FILES PER SCENE
  Limit: 20
  Used:  12 (all 12 slots
         PLAYGAME reads for
         the title scene, all
         11 for every world,
         all 4 for the ending)
  Where: all scenes

MAP SIZE
  Limit: 100 x 100 blocks
  Used:  98 maps, every one
         100 x 100 and
         wrapping all the way
         round
  Where: *.MAP

MONSTERS PLACED ON A MAP
  Limit: 200
  Used:  200 in the Maelstrom
         (every slot: not one
         left for a shot);
         6682 in all
  Where: MAEL.MAP

MONSTERS IN A .MON
  Limit: 64
  Used:  64 in each of 9 files
         (576 monsters: 4
         families of 44
         creatures, each in an
         easy and a hard

         own file with the

         phases, plus the
         courier's own shots

  Where: *.MON

  Used:  all 20 in every

         with varied timing
  Where: *.MON

  Where: *.MON, SECTOR1.MAP

Some limits shaped the game:

* Game-Maker animates block
  TYPES on one clock, so every
  force field of a world
  blinks together. Vending
  pads cannot restock without
  restocking all at once, so
  each sells one of each per
  visit.
* A scene reloads its map each
  time you enter, so
  star-shards are counters
  (20..29), not objects: a
  shard cannot be counted
  twice and gates test for it
  without using it.
* The Maelstrom fills all 200
  monster slots, so there is
  no slot left for a single
  shot: in the storm, weapons
  jam.
* Every map wraps, so every
  planet is a little globe:
  walk east long enough and
  you come home.
* One big GIF per sector holds
  every planet card and every
  long-range scan; each .BKD
  file shows its own 320x200
  window of it, so 176
  pictures load from 5 files.
* A character has 20 key
  sequences, each with one
  key, and Maximus uses all 20
  (moves, blaster, six module
  weapons, two dashes, hover,
  pick up, drop, hail). There
  is no slot left to give
  W/A/S/D a copy of the
  arrows.
