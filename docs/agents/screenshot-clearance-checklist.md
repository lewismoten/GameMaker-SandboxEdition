# Screenshot clearance checklist

For anyone adding a picture to the repository, the README, a blog post or a release. A screenshot is a copy of a screen, and a screen can carry more than it seems to.

## Before you take it

- Use a clean browser profile or a test account, not a daily one.
- Close other windows, tabs and notifications. Turn on Do Not Disturb.
- Use sample data, not real files, names or messages.
- Start the game with no hidden unlocks showing that the page should not show.

## Look at the whole picture

- Taskbar, dock, menu bar and window titles: do they show other apps, tabs, file names or a user name?
- Address bar: local paths, ports, hostnames, tokens in the URL?
- File pickers and Files-style apps: they list private folders. Treat any picture of one as private, and do not crop and publish it.
- Notifications, badges, clock, battery, carrier and Wi-Fi name on a phone.
- Reflections or a person in the shot.
- Zoom in at 200 percent and read every word.

## Ownership

- Is every image in it yours, openly licensed, or from this project's own assets?
- Third-party game screens, scans and archive files: do not publish without written permission.
- Reference photos used only to draw from stay out of the repository.
- AI-made art: credit the tool in NOTICE.md.

## Content rules of this project

- No secret game visible, named or implied.
- No real addresses, plates or phone numbers. Fake ones follow the project's rules.
- Art passes the stranger check: nothing rude, scary, religious or like a famous character by accident.
- Light and dark: confirm the theme in the shot is the one you meant.

## After

- Save the original and an edited copy separately; strip metadata (location, device, time) from the published copy.
- Write alt text.
- Note date, commit and caption beside the file.
