# Working with AI coding agents on this project

This project was built largely by AI coding agents (Claude Code and others) working in
parallel, with the maintainer steering, playing the results and asking again. These pages
describe what that work taught, in terms that apply to other projects too.

- [Lessons learned](lessons-learned.md): principles for running coding agents, each tied to
  a commit, check or document in this repository.
- [The task bank pattern](task-bank-pattern.md): how a recurring task bank, handoff notes and
  agent briefs keep long, parallel runs on track, with made-up examples.
- [How I built this](how-i-built-this.md): the maintainer's account of building the project with
  agents, what went wrong and what changed.
- [Handoff note template](handoff-template.md): a one-page note an agent leaves so the next
  session can continue, with an invented example.
- [Screenshot clearance checklist](screenshot-clearance-checklist.md): what to check before a
  picture goes into the repository, README, blog post or release.
- [A small mailbox for agents](mailbox-design.md): a design note for agents leaving messages
  for each other in a plain folder.

The standing rules agents follow here are in [`AGENTS.md`](../../AGENTS.md) and
[`CLAUDE.md`](../../CLAUDE.md).

These pages were written with Claude (Anthropic's AI model) from the maintainer's notes, and
edited by the maintainer's process like the rest of the repository. See
[`NOTICE.md`](../../NOTICE.md) for how AI tools are credited.
