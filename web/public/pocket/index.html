Game-Maker Pocket Player: install

This puts the Pocket Player on a small ESP32 touch-screen board. It writes the whole board, so it replaces what was on it.

1. Which board?

Pick the one you have. The model name is printed on the back of the board.

The pictures are drawings, not photos. Boards from different sellers can look a little different; the printed model name is what counts.

2. Install

  1. Use desktop Chrome or Edge. Firefox, Safari and phones can't do this.
  2. Plug the board into the computer with a USB cable that carries data.
  3. Pick your board above, click Install, choose the board's serial port, and click Install again.
  4. Wait for it to finish (about a minute). The board restarts by itself.

Pick a board first.

About Wi-Fi setup (Improv)

The install window can also offer "Connect to Wi-Fi" once the board has restarted. That works when the board's program speaks Improv Wi-Fi, a small open protocol that sends the network name and password over the same USB cable, so nothing is typed on a tiny screen. The Pocket Player doesn't speak it yet, so you won't see that button. It is planned for when the player can fetch games over Wi-Fi.

Games go on the board's microSD card, in a folder named pocket. The README in hardware/pocket-player/ says what the screen should show.
