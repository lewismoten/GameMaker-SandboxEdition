Game-Maker Pocket Player: install

For the ESP32-3248S035 (3.5 inch, 480 by 320). This writes the whole board: it replaces what was on it.

  1. Use desktop Chrome or Edge. Firefox and Safari can't do this.
  2. Plug the board into the computer with a USB cable that carries data.
  3. Click Install below, pick the board's serial port, and click Install again.
  4. Wait for it to finish (about a minute). The board restarts by itself.
This browser can't flash a board. Use desktop Chrome or Edge. Open this page from http://localhost or https, not a file.

Then see hardware/pocket-player/README.md for what the screen should show.
