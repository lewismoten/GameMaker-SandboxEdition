# Community games

`games.json` is the reviewed list of independently hosted games. `catalog.ts` validates
its metadata and the entries generated by the submission form. Loading the list does not
fetch game files or run remote code. The creator's play URL remains the game's permanent
destination; an optional archive URL downloads one game-file ZIP.

Each entry has a unique `id` (up to 48 characters: lowercase letters or digits in groups
joined by single hyphens), `title`, `author`, HTTPS `url`, and a short `summary`.
`catalog.ts` requires absolute HTTPS URLs without credentials, up to 2,048 characters;
it does not check that the host is reachable or the archive is a valid game.
Optional `sourceUrl`, `imageUrl` and `archiveUrl` point to the creator's source
and credits, a preview image, and a permanent game archive. Preview images should allow
anonymous cross-origin loading. Metadata uses plain text. Counterparts on other sites
keep their own game files, licenses and notices.

THE CHEZ links to the standalone Vite integration project at its maintainer-confirmed
GitHub Pages address. Its Teddy preview and ZIP paths match that project's build output;
no artwork or game files are copied into this catalog.

`homeGame.ts` adapts an entry to the home library's model. It draws a title card immediately
and loads the optional creator image anonymously in the background, shared between the
tile and featured preview. Missing images leave the title card usable. Native files and
demo playback are not part of listing or previewing a Community entry.

`submit.ts`, loaded only by Add your game, generates and validates a local metadata entry.
Its copy button and GitHub links guide the creator through forking, editing the JSON list,
and proposing a pull request. The editor link targets this repository's list, not a
detected personal fork; the creator must select their fork before editing.
The form never submits a draft or changes the catalog itself.
See [the contribution guide](../../../docs/community-games.md) for the JSON fields.
