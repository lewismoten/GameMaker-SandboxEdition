Game-Maker: Sandbox Edition Guide

Playing

Each game sets its own keys, usually the arrow keys and a few others; Keys on its page shows them. These keys work in every game:

EscLeave a level or a screen
F1The game’s instructions
F2Status and inventory
F3 / F4Music / sound on or off
F5 / F6Save / restore the game

Game pads work as joysticks. On a touch screen, buttons appear for the directions and for every key the character uses. Saved games and high scores stay in this browser; Saves & scores on the game’s page shows them.
