Library

The Library gathers everything to read and print in one place. Browse it by game or by type; each piece opens to read page by page or to print.

What is on the shelves

  • A manual for each game, and a hint book where a game has one
  • Maps of the levels
  • The Sandbox Scoop, the newsletter, and sticker sheets and cards
  • The Game-Maker box's own paper, with the Owner's Guide
  • TURBO BUTTON, the shareware gamer's magazine
  • The Guide to the web editor
